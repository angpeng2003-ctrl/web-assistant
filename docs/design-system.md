# 建站助手 · 设计规范

2026-11-20 用 UI/UX Pro Max 定（查询：internal productivity tool client intake workflow form；variance 3、motion 2、density 6）。以后改界面照这份做；样式都在 `public/style.css` 顶部的变量里。

## 方向

- **风格**：极简、瑞士风格（Minimalism & Swiss Style）。适合专业工具：留白清楚、层级靠字号和粗细，不靠阴影和花哨装饰。
- **动效**：轻。只用 150–200ms 的颜色、边框过渡；尊重系统“减少动态效果”设置。
- **密度**：标准。正文 15–16px，行高 1.6。

## 颜色（浅色 / 深色都有）

| 用途 | 浅色 | 说明 |
|---|---|---|
| 主色（按钮、选中） | `#0F766E` | 推荐的 `#0D9488` 配白字对比度不够 4.5:1，压深一档 |

| 强调（交付、待你处理） | `#C2410C` | 推荐的橙色 `#EA580C` 压深一档，保证白底文字对比度 |

| 卡片 | `#FFFFFF` | |

| 次要文字 | `#4B5B58` | |
| 边框 | `#D3E0DD` | 推荐的 `#99F6E4` 在密集表单里太跳，改柔和 |

## 字体

推荐的是 Plus Jakarta Sans，但建站助手只在本机运行、页面安全策略不允许加载外部字体，而且界面以中文为主，所以用系统字体：`"Microsoft YaHei UI", "PingFang SC", "Noto Sans SC", system-ui`。数字用 `tabular-nums` 对齐。

## 交互规则

- **不用浏览器原生弹窗**（`confirm`/`prompt`）：一律用页面内对话框，标题说清要做什么，正文说清后果和能不能恢复；危险操作的确认按钮用红色，默认焦点放在“取消”。
- **位置记在网址里**：`#/客户编号/步骤`，刷新不丢，浏览器“后退”能回到上一步。
- **保存状态常驻顶栏**：正在保存 / 已保存 时间 / 有几处没保存（点它跳到出错的地方）。
- **图标**用内联 SVG（Lucide 线条风格），不用 emoji；只有图标的按钮必须有文字标签或 `aria-label`。
- **点击区域**：电脑上按钮至少 36px 高，触屏（`pointer: coarse`）至少 44px。
- **反馈**：成功提示 3–4 秒自动消失；错误提示留 7 秒且可以手动关；表单错误显示在对应题目下方，并用 `role="alert"` 读出。
- **焦点**：所有可操作元素有清楚的焦点框；对话框打开时焦点移进去，关闭后回到原来的按钮。
- **步骤条**：显示“第几步，共 4 步”，做完的步骤打勾。

## 交付前自查

- 375px、768px、1024px、1440px 宽度下没有横向滚动。
- 浅色和深色下文字对比度都至少 4.5:1。
- 不用鼠标、只用键盘能完成新建客户、填资料、生成说明。
- 系统开了“减少动态效果”时没有过渡动画。
